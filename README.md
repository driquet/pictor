pictor is an image toolbox for Go, usable both as a CLI tool and as a library.

## Status

- `tiff`: standalone TIFF 6.0 read/write codec — available today as a library.
- CLI: planned, not yet implemented.

## Install

```sh
go get github.com/driquet/pictor
```
